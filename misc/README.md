# Misc

| Notebook | Description |
|---|---|
| [`weather-api.ipynb`](weather-api.ipynb) | Getting current weather from OpenWeatherMap with `requests` and `pyowm`. Replace `YOUR_API_KEY` with your own free key from [openweathermap.org](https://openweathermap.org/api). |
| [`face-detection-opencv.ipynb`](face-detection-opencv.ipynb) | Detecting faces with an OpenCV Haar cascade. To run it, add a photo named `Image.jpg` and OpenCV's [`haarcascade_frontalface_default.xml`](https://github.com/opencv/opencv/blob/master/data/haarcascades/haarcascade_frontalface_default.xml) saved as `model.xml`. |
| [`chatbot-api-client.ipynb`](chatbot-api-client.ipynb) | A simple command-line chatbot that sends questions to a chat API with `requests` (the course server it used may no longer be online). |
